# dsh-api-client 知识库

本项目踩坑与经验的沉淀。**接到任务先扫下方索引，命中主题必读再动手；收口时按标准蒸馏新主题**（规则见 AGENTS.md §七）。

- **收录标准**（三条同时满足）：可复用（后续还会遇到）、非显然（读代码/官方文档推不出）、已实证（本项目验证过，注明来源）；
- **三路分流**：项目事实与规范 → PROJECT.md；一次性事件 → docs/DEVLOG.md；可复用经验与方法论 → 本库；
- **格式**：一主题一文件（kebab-case 命名，不带日期/版本号，原地迭代），索引一行一条；
- **毕业路径**：主题成熟且跨项目通用 → 提炼成独立 skill，本库文件改为指向 skill 的存根。
